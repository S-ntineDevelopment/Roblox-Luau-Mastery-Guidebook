# Roblox Luau Engineering Guidebook

A fact-checked curriculum for choosing and verifying Roblox/Luau architecture, networking, data-oriented design, combat security, AI/NPC, tooling, scaling, and LiveOps techniques.

This repository intentionally contains the learning curriculum only. It excludes project agent instructions, private project policies, implementation checklists, and engine-specific operational documents.

## Scope

The guidebook treats patterns as options, not maturity requirements. It distinguishes platform facts, security requirements, engineering heuristics, project policy, and claims that need profiling or runtime proof. Each stage includes primary Roblox/Luau references and explicit applicability guidance.
