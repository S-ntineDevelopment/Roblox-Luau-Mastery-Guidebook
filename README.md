# Roblox Luau Mastery Guidebook

A curriculum-first guidebook for mastering Roblox Luau architecture, networking, data-oriented design, gunkit security, AI/NPC systems, tooling, scaling, and LiveOps.

This repository intentionally contains the learning curriculum only. It excludes project agent instructions, private project policies, implementation checklists, and engine-specific operational documents.

## Scope

The guidebook is written for Roblox Luau projects that need reusable systems, explicit contracts, server authority, typed networking, performance-aware architecture, and long-term maintainability.
