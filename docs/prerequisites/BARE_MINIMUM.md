# Bare Minimum Prerequisites

This is the entry point, not an architecture checklist. The numbered curriculum teaches tables, ModuleScripts, types, metatables, structures, and systems in order.

## Before Stage 1

Be able to:

- create and run a Script in Roblox Studio;
- use local variables and the values `number`, `string`, `boolean`, and `nil`;
- write `if` statements and basic `for` or `while` loops;
- call `print()`;
- read the Output window and follow a file/line error.

You do not need ECS, OOP, dependency injection, networking, persistence, metatables, advanced types, or a framework before Stage 1.

## Learning rule

1. Run the visible lesson unchanged.
2. Predict and explain every assertion.
3. Complete the **Try it** task.
4. Stop before reference material if the beginner behavior is unclear.
5. Do not adopt architecture merely because it appears later.
